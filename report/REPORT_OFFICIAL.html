Abstract

Multi-agent tool teams can split a harmful goal across agents so each local step looks like routine ops, and a judge that scores steps in isolation can miss the composition. Co-occurrence heuristics that only pair secret-path touches with outbound tools catch many splits but false-positive on benign audits that touch the same path without leaking the secret value. This weekend project builds a tiny deterministic sandbox of scripted agents and stub tools (no network, no real credentials) and compares seven offline monitors on seven labeled scenarios: five compositional exfiltration attacks (overt, stealth, fragment, encoded, and hex-chunked) and two benign cases including a hard negative. Monitors range from a single-step keyword judge through co-occurrence and majority/trusted baselines to exact value-flow taint, fragment coverage, and encoded-taint that also matches reverse, base64, and hex forms. On this toy set, encoded_taint is the only monitor with detection rate 1.0 and false-positive rate 0.0; co-occurrence baselines reach detection 1.0 but false-positive 0.5 on the path-touch audit; exact taint restores precision but misses fragment and encoding attacks. The takeaway for multi-agent oversight is that sensors that only co-occur can look strong until a hard negative or a split/transform adaptive attack is added. All numbers come from a fixed offline harness (53 pytest cases); this is not a claim about production LLM agents.

1. Introduction

Multi-agent tool teams can decompose a harmful goal so that each local step looks like routine operations (list a directory, read a config, stash a note, send a status ping). A judge that scores steps in isolation can miss the composition. Trajectory heuristics that only co-occur “secret path touched” with “outbound tool used” can catch many splits, but they also false-positive on audits that touch the same path and send mail without leaking the secret value.

This weekend project builds a tiny deterministic sandbox (scripted agents, stub tools, no network) and compares seven offline monitors on seven labeled scenarios. The intended contribution is not a production detector, but a clear decision matrix: single-step vs co-occurrence vs value-flow / fragment / encoded-taint, including adaptive attacks that defeat earlier taint rules.

Our main contributions are:

  1. A reproducible offline sandbox and labeled scenario suite for multi-agent split-harm tool trajectories, including a hard-negative path-touch audit.
  2. A head-to-head comparison of seven monitor families on detection vs false-positive rate on that suite.
  3. Evidence that co-occurrence looks strong until hard negatives and fragment/encoding adaptive attacks are added, and that successively stronger value-flow rules recover precision and coverage on this toy set.

2. Related Work

Compositional and multi-agent prompt-injection style attacks motivate the framing that harm can be split across agents so local steps look mild (Lee & Tiwari, 2024). Trusted-monitor / AI-control protocols motivate conservative oversight baselines that prefer precision over recall when scoring suspicious trajectories (Greenblatt et al., 2024). Our work differs in focusing on a deterministic tool-trajectory sandbox and offline value-flow monitors rather than learned judges or live LLM oversight. RedLoop / Gray Swan IPI ideas were technique inspiration only and are not copied into this tree (see Appendix A).

3. Methods

3.1 Sandbox

The package split_harm/ runs scripted agents (typically 3–4 per scenario) against an in-process tool registry and shared key/value memory. Stub tools include list_dir, read_file, write_memory, read_memory, post_webhook, send_mail, plus benign helpers. There are no network sockets, no real credentials, and no production systems: outbound tools append to an in-memory log. Trajectories are deterministic scripts, not LLM-sampled. Secret-bearing vault paths used in harmful and hard-negative scenarios are vault/secret.txt (SECRET_TOKEN=toy-exfil-token-NOT-REAL) and vault/cfg.dat (AUTH_CODE=alpha-bravo-991).

3.3 Monitors

  1. SingleStepJudge — per-step keyword score; FLAG if any step crosses threshold.
  2. TrajectoryMonitor — full-trace co-occurrence of secret-touch markers/paths with outbound tools.
  3. MajorityMonitor — N=5 jittered TrajectoryMonitor threshold replicas; FLAG on majority vote (not independent model samples).
  4. TrustedMonitor — FLAG only when secret-touch and outbound both present.
  5. TaintMonitor — value-flow: FLAG only if a tainted value appears in an outbound field.
  6. FragmentTaintMonitor — 5-character shared-substring coverage of each secret across outbound blobs; FLAG if coverage ≥ 0.6.
  7. EncodedTaintMonitor — plaintext fragment coverage plus reverse / base64 / hex of wholes, halves, and sliding min_frag windows; FLAG if reconstructed coverage ≥ 0.6.

Metrics: detection rate = fraction of harmful scenarios FLAGged; false-positive rate = fraction of benign scenarios FLAGged. Harness: run_scenario + monitor evaluate; table via scripts/report_table.py.

5. Discussion and Limitations

On this toy set, co-occurrence is high-recall / high-FP; value-flow restores precision on path-touch audits; adaptive fragment and encoding attacks force successively stronger taint rules. A weekend takeaway for Track 4 is that oversight that only co-occurs sensors can look strong until a hard negative or a split/transform adaptive attack is added.

Limitations. Small n (seven synthetic scenarios); rates are exact on this set, not estimates with confidence intervals. Deterministic scripts, not LLM-sampled trajectories. Offline heuristic monitors, not learned judges or live LLM oversight. Taint / fragment / encoded rules are path/value heuristics for this sandbox, not general program analysis. Majority “replicas” are threshold jitter, not independent model samples. Encoded transforms covered are reverse / base64 / hex of wholes, nearby halves, and sliding min_frag windows; other encodings or steganography are out of scope.

Dual-use / ethical considerations. The attack harness exists for evaluation only. Tools are in-process stubs with no real credentials, no production systems, and no live network. Secret strings are toy placeholders. Do not reuse scenario designs, fragment/encoding patterns, or monitor-evasion ideas to attack deployed agent teams. Describing how compositional exfil can evade weak monitors has dual-use character; we mitigate by stub-only tools, no network, explicit eval-only framing, and focusing the write-up on detection and false-positive tradeoffs rather than operationalization against real systems.

Future work. Scale to LLM-sampled trajectories, richer encodings, and learned or trusted-model monitors under the same hard-negative discipline.

6. Conclusion

On a fixed seven-scenario offline harness, encoded value-flow monitoring uniquely achieved perfect detection with zero false positives, while co-occurrence baselines paid a hard-negative false-positive cost and weaker taint rules missed fragment and encoding adaptive attacks. The practical message for multi-agent oversight is to evaluate monitors against both compositional attacks and path-touch audits that never leak values.
